# Calculator-Bat-Ball-Stump-Game-
Calculator &amp; Bat Ball Stump Game  using html , css and js
🧮 Calculator & Bat Ball Stump Game – JavaScript Mini Projects

This repository contains two interactive mini projects built using HTML, CSS, and JavaScript:

A Functional Calculator

Bat Ball Stump Game (a simple logic-based game similar to Stone Paper Scissors)

These projects focus on strengthening core JavaScript concepts such as DOM manipulation, event handling, conditional logic, and user interaction while keeping the UI clean and responsive.

🎯 Projects Included
🔢 Calculator

A fully working calculator that performs basic arithmetic operations with a user-friendly interface.

Features

Addition, Subtraction, Multiplication, Division

Clear and Delete functions

Responsive button layout

Real-time display updates using JavaScript DOM manipulation

🏏 Bat Ball Stump Game

A fun browser game where the user plays against the computer by selecting Bat, Ball, or Stump. The computer randomly chooses its move and the result is displayed instantly.

Game Logic

Bat beats Ball

Ball beats Stump

Stump beats Bat

Features

Random computer choice generation

Score tracking

Instant result display

Interactive UI with JavaScript

🛠️ Tech Stack

HTML for structure

CSS for styling

JavaScript for logic and interactivity
